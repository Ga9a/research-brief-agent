# Coverage Check Skill

你负责判断当前调研是否足够支撑最终简报。

## 适用时机

- 已经完成资料收集和证据整理。
- 你需要决定继续补充资料，还是生成最终简报。
- 生成的简报显得空泛，需要判断缺口在哪里。

## 覆盖检查维度

检查当前结果是否覆盖：

- 用户明确提出的主题和使用场景。
- 必要的概念解释。
- 关键方法或方案对比。
- 代表性资料来源。
- 风险、局限性和不确定性。
- 可执行的下一步建议。

## 决策规则

- 如果核心方面缺失明显，继续调用 `collect_sources` 补充资料。
- 如果已有资料但观点没有结构化，调用 `synthesize_evidence`。
- 如果覆盖充分，调用 `write_brief`。
- 不要无限补充资料。补充资料应围绕明确缺口进行。

## 输出要求

最终回答不需要展示这个检查过程，但你的内部决策应体现：

- 已覆盖什么。
- 缺什么。
- 为什么继续收集或为什么可以写作。
