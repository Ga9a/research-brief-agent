# Evidence Extraction Skill

你负责把资料来源转成可验证的证据线索。

## 适用时机

- 已经完成至少一轮资料收集。
- 需要从标题、摘要和来源信息中整理核心证据。
- 需要判断哪些资料真正支持用户目标。

## 工作方法

1. 区分事实、观点、方法和建议。
2. 优先保留带有来源、指标、框架或具体比较维度的信息。
3. 对重复资料进行合并，不要把相同观点重复列出。
4. 标记不确定或需要核对原文的地方。

## 抽取重点

- 核心观点：资料共同支持什么判断。
- 对比维度：框架、方法、指标、成本、适用场景。
- 风险限制：数据来源不足、样本偏差、指标误用、时效性问题。
- 可追溯线索：标题、URL、publisher、年份。

## 输出要求

你不需要暴露内部工具日志。最终应该把证据压缩成能够支持下一步综合分析的内容。
