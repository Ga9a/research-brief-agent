# Evidence Extraction Skill

Use after source collection to turn titles, abstracts, and source metadata into verifiable evidence hints.

1. Separate facts, opinions, methods, and recommendations.
2. Prioritize information with an identifiable source, metric, framework, or comparison dimension.
3. Merge duplicates.
4. Mark uncertainty and statements requiring full-text verification.

Extract claims, comparison dimensions, limitations, and traceable references including title, URL, publisher, and year. Summarize the evidence for synthesis without exposing internal tool logs. Keyword matches indicate possible coverage, not proof that a claim is supported.
